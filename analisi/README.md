# 📌 Analisi del Progetto – Gestionale Veterinario

## 🐾 Introduzione

Questa cartella contiene l’**analisi del progetto** relativo allo sviluppo di una web application per la gestione di uno studio veterinario.

L’obiettivo del sistema è digitalizzare e centralizzare le principali attività dello studio, tra cui:
- gestione degli utenti (proprietari)
- gestione degli animali
- prenotazioni e visite
- prestazioni veterinarie
- diario clinico e ricette
- fatturazione e reportistica

## 🧠 Contenuti dell’analisi

Il documento descrive in dettaglio:

- modello E-R del database

- gestione delle prenotazioni e visite
- struttura della fatturazione
- report e dashboard
- vincoli funzionali e logici
- architettura logica del sistema

---

## ⚙️ Note tecniche

Il sistema è progettato come una **web application** e utilizza:

- database relazionale (PostgreSQL)
- autenticazione tramite token (JWT)
- gestione dei ruoli a livello applicativo
- separazione tra dati clinici e amministrativi

---

## 👨‍💻 Obiettivo finale

L’obiettivo del progetto è realizzare un sistema scalabile e modulare per la gestione completa di uno studio veterinario, migliorando l’efficienza operativa e la gestione dei dati clinici.
